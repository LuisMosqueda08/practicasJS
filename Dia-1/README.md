# Bootcamp de JavaScript — Día 1: Arrays, `length`, `push()` y `pop()`

## Objetivos del día

- Comprender qué es un array y qué problema resuelve.
- Leer la cantidad de elementos con `length`.
- Agregar un elemento al final con `push()`.
- Quitar el último elemento con `pop()`.
- Distinguir entre el valor devuelto por una operación y el cambio producido en el array.
- Practicar el razonamiento paso a paso antes de escribir código.

## Tiempo aproximado

Entre 2 horas 30 minutos y 3 horas 30 minutos. Avanza a tu ritmo: comprender importa más que terminar rápido.
